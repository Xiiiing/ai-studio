# 提示词工作台（0.2.1）

关联 [#74](https://github.com/Xiiiing/ai-studio/issues/74)，依赖已验收的 [质量比较台 PR #72](https://github.com/Xiiiing/ai-studio/pull/72)。本阶段仍需用户实测；不等同于审核通过、合并或稳定版发布。

## 入口与操作

整剧打开 **项目资料 → 提示词工作台**，制作单元打开 **更多 → 提示词工作台**，长剧集可直接选择同名页签。

1. 选择岗位与任务合约。同一岗位可能分别承担剧本分镜、部门安排及 H3 编译，合约单独管理，不能跨任务替换。
2. 从内置模板或历史版本开始编辑六段内容：岗位职责、项目要求、制作规格、模型适配说明、参考资料说明、返修要求。填写名称，**保存为新版本**。旧版本不可覆盖；编辑后再次保存会得到独立版本。
3. 填写符合岗位输入合约的任务 JSON；可从页面下方的实际调用载入。点击 **预览装配与差异**，检查参数展开、最终角色文本、模型协议规则、段落来源、输入/输出合约。可选任一已保存版本作为比较基线。预览不调用模型。
4. **验证已保存版本**检查输入合约、模板与规格装配，不执行模型。结构有效、JSON 合法和试运行完成都不能证明创作质量提高，仍需人工检查实际返回。
5. 在项目空闲、无在途任务时，**将此版本应用到项目**。如仍有排队或执行任务，先暂停并等待结束，再刷新重新准备。此操作仅更新提示词快照，不生成、不批准素材、不重置剧本或成片。需要重做时继续使用原有定向返修入口。
6. 可以选择旧版本重新应用，或将该岗位回退内置模板；其他岗位保持原选择。项目附加要求单独保存，可在“仅此项目的附加要求”中编辑；这些内容在岗位模板之后装配。
7. “公共默认版本”属于高级配置：已保存版本必须有成功装配验证及此版本的成功试运行记录，再勾选人工确认后启用。它只影响此后创建的新项目。已有项目要另行点击 **显式应用当前公共默认**；子剧集、单元使用各自快照，需分别应用。公共默认也能回退内置或已验证的旧版本。

默认运行保持内置模板原字节和旧缓存规则。启用工作台版本后，使用受限参数 `{{shot_count}}`、`{{duration_seconds}}`、`{{character_ids}}`、`{{speech_limit}}`、`{{format}}`；没有表达式、脚本或任意对象插值。旧模板的字符串兼容转换继续服务原项目；工作台模板在参数展开后直接追加结构化制作规格与项目硬要求，不再经过那组字符串替换。输入超过上下文窗口时沿用原检查，拒绝提交而不静默裁剪。

“模型适配说明”是角色文本，不能修改模型连接、工具权限或输出 schema。参考资料中的指令不能提高权限；实际模型返回仍须满足原业务校验。已确认材料在任务输入中继续保留固定引用，工作台不会根据提示词更改素材选择。

## 隔离试运行

试运行只执行已保存版本，固定当前项目版本、输入、覆盖项、输出合约和已预览的模型配置。需在预览后勾选明确授权，设置 **128–16384 输出 tokens**，点击启动。当前仅开放已配置的内网 llama.cpp / Ollama native 推理，费用未知的供应商提交不会启动；完整供应商费用与项目制作授权属于后续阶段。

worker 在生产队列空闲时执行独立试运行队列，每次最多一次生成请求，schema 重试为 1 次、单次生成 HTTP 超时为 60 秒；模型发现和上下文检查仍执行。结果仅保存在试运行记录中，不写回提案、剧本、审核、资产、预算账本或成片，也不代表质量改善。

排队项可通过“结束此试运行”取消。执行进程中断或无法确认结果时标为 **unknown**，保留回执并阻止新增试运行；重启不会自动再次请求模型。核实后可结束该项，保留所有记录。迟到结果只作为该试运行的证据保存，不能替换生产成果。浏览器请求超时保留原请求 ID，可重试同一操作；服务器不会重复入队。

## 实际调用与持久化

升级后的模型调用保存 `assembly.json`：最终角色文本、协议装配规则、实际任务输入、输出 schema、参数、模型摘要及提示词版本/段落来源。调用回执同时保存装配身份；不能用今天的模板补写没有记录的历史调用。

工作台下方读取当前项目最多 80 条留有装配证据的创作/H3/对白调用；完整历史仍保存在原调用目录及质量基线中。旧记录显示缺口，原请求与已批准素材不会变化。全剧规划等尚未注册的内置任务指令会保存实际调用证据，本阶段不将它们冒充可编辑的注册角色合约；为这些任务补独立合约应在相应执行阶段升级。

不可变版本、公共默认、操作幂等记录及试运行状态存于实例自己的 SQLite；项目快照内嵌所选版本全文，不依赖后续公共默认。非空提示词快照进入创作缓存身份；H3 编译缓存也计入工作台身份，文本相同的新版本仍有独立身份。新增表已接入原有备份 schema 校验，旧数据库无需迁移项目记录。试运行原始请求回执保存在 `DRAMA_FACTORY_DATA/prompt-trials/`，私有数据目录须随实例备份；这些回执不在现有仅封存 production 的素材包中。

保存、应用、启用和试运行均具有请求幂等；应用检查项目 revision 及项目/子项目在途任务。新版本不会重写过去调用，不会自动采纳试运行返回，也不会覆盖独立审核结论。

## 验收建议

先冻结一份质量基线；保存并预览一个只改动作因果的候选；验证后应用到已暂停的制作单元，执行一次原有文本返修，再从实际调用中确认最终提示词及来源；冻结第二份质量基线比较。检查回退后未受影响的素材仍保留。真实模型或成片效果比较仍需用户选择样例与预算，不能用本页的结构验证或模拟测试代替。
