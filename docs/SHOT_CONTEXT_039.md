# 逐镜制作依据与影响预览（0.3.9）

镜头制作台在候选对比与单镜精修之间集中展示固定素材版本、来源校验值、剧情目标、人物状态和参考镜头。候选卡可展开参考与有效参数，并在人工采用前显示受影响镜头和阶段。缺少历史记录时直接说明缺口，不补造来源。

修改首帧影响本镜首帧、视频及传递引用它的镜头；采用已有首帧保留该图片，重做本镜视频和后续引用。仅修改视频不使无关首帧失效。接口的 `operation_impact` 是绑定当前项目 revision 的只读预览，保存时仍执行原 CAS、空闲与云提交对账校验。运行任务尚未退出时页面只读。

预览不生成、不授权费用、不删除历史。保存后项目保持暂停；恢复制作仍走原 worker、独立审核与费用授权。桌面并排展示依据，手机单列展示；候选比较与人工选择沿用原入口。
