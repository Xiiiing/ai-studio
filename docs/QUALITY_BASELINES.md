# 质量基线与比较台

0.2.0 对应 [Issue #62](https://github.com/Xiiiing/ai-studio/issues/62)，属于 [0.2 升级路线](AGENT_020_ROADMAP.md) 的第一阶段。

## 使用

整剧打开 **项目资料 → 质量比较**；长剧集选择 **质量比较**；制作单元选择 **审核 → 质量比较**。规划尚未确认、还没有生成制作单元时，也可以冻结整剧的需求、调用与规划审核。填写快照名称并点击“冻结当前版本”，修改方案后再保存一份，分别选择基线与候选，即可查看累计运行投入和已有审核记录的变化。不同层级分别保存，不将整剧规划通过冒充单元媒体或整片质量通过。

冻结只读取数据库和已有调用文件，不执行模型、重新解码媒体、提交生成、批准素材或修改项目。关闭页面不会改写已发布快照；请求响应不确定时可重试同一请求，服务端按请求编号返回原快照。

## 保存什么

- 数据库只读事务中的项目快照与云任务记录，包括需求、反馈、制作规格、固定材料、已有剧本和媒体回执。
- 实际调用 receipt、request、context、response 和 parsed 文件，以及当次提示词版本/哈希、模型身份、配置修订、参数和输入哈希。失败响应也随快照保留。没有历史身份时显示未知，不用当前模型设置补齐。
- 当前服务提交与快照实现哈希。这是执行冻结操作的代码身份，不是历史模型调用所用源码的证明。
- 当时的故事/分镜审核、逐镜图像与视频 QA、对白时长实测及成片技术 QA；保留失败记录。已有审核不在本页重新验证。

私有文件写入 `DRAMA_FACTORY_DATA/quality-baselines/<project_id>/<request_id>/`，不进入 Git，也不通过媒体接口公开。API 只返回明确选择的摘要、哈希与审核字段，不返回原始项目、请求原文或模型连接。文件与目录使用 0600/0700 权限。

每次快照通过完成清单校验，临时目录完成后原子发布。列表校验项目与快照元数据，选中详情或比较时再校验全部调用文件，避免列表反复读取所有历史请求。冻结前后检查项目版本及已读取调用文件，变化时返回 409；项目数据库和文件系统不是同一个原子事务，历史证据只能代表冻结时读到并校验的状态。

## 如何解释指标

- 操作耗时是**累计已记录操作的耗时之和**，并行工作不能据此推算端到端用时。另列项目实际记录的制作累计用时。
- JSON 结构重试来自调用 receipt 的 attempts；提案/剧本返修来自各自实际 rounds。缺记录时不是零。
- 费用仅汇总数据库已有云任务，按币种分开列出估算部分与确认部分。零费用必须有明确的零值记录；缺失费用、没有云任务及未计价的文本/本地模型调用均不能当作免费。
- 快照需求指纹相同仅表示所列项目目标/固定材料相同；调用上下文和实际输出还需查看各自证据。需求或固定材料变更时明确提示不能作为同输入效果实验。
- 历史审核通过、分数变化和运行投入变化都不会将 `quality_conclusion` 从 `not_established` 改为“效果改善”。

真实效果比较继续使用 [CREATIVE_AB_PROTOCOL.md](CREATIVE_AB_PROTOCOL.md) 的冻结、匿名评审、失败保留及 holdout 约束，以及 [QUALITY_EVALUATION.md](QUALITY_EVALUATION.md) 中的实际媒体评估。现有 CLI 不自动执行模型；本页也不提供隐式收费运行。匿名评测尚未运行时始终显示 `not_run`，不能拿合成测试或历史审核替代真实观察。

## API

| 操作 | 路径 | 输入 |
|---|---|---|
| 列表 | `GET /api/factory/projects/{pid}/quality-baselines` | 无查询参数 |
| 冻结 | `POST /api/factory/projects/{pid}/quality-baselines` | `request_id`（32 位小写十六进制）、`label`（1–80 字符）、`expected_revision` |
| 详情 | `GET /api/factory/projects/{pid}/quality-baselines/{id}` | 无查询参数 |
| 比较 | `GET /api/factory/projects/{pid}/quality-baselines/compare` | 单值 `baseline`、`candidate` |

每项目最多 100 份快照；每次最多 240 条角色调用、80 个镜头、每镜头 100 条制作尝试。文件和输入有大小限制；调用无法完整读取时列入缺口，指标只表示已捕获部分。损坏快照保留文件并显示不可读数量，不改写或用当前状态修补历史。快照不是素材备份；需要长期重放时另行保留原始媒体及独立评测封存。
