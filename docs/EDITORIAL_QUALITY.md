# 审核与返修边界（0.3.5）

新项目固定 `creative_quality_contract` 版本。现有项目保持原契约，可在暂停、无运行任务、已核对外部提交后明确启用；启用不重写历史，也不触发模型或媒体请求。当前稿件重新独立审核之前不能恢复制作。

新审核为每项问题记录结构/客观/创作建议/审美分类、正文位置、来源 ID、影响和最小修订目标。证据目录从当前输入稿件构建，引用不存在的来源不能通过输出合约；实际来源文本、内容签名与审稿版本一起保留。新模板不会补写旧调用的分类或证据。

只有有当前证据的重大结构或客观问题能自动返修。创作建议及审美选择保留给作者；会改变作者意图的选择明确停止。数字评分仍保留原门槛，分数低但没有可验证问题时停止并保留原稿，不反复自动重写。局部返修只采用允许镜头的返回，保留其他镜头和原有元信息；返修后仍须重新独立审核。

接口：`POST /api/factory/projects/{id}/creative-quality`，提交 `expected_revision`、`request_id`、`confirmed=true`。响应沿用项目快照；读取历史不触发迁移。工作台的审核依据面板展示分类、当前证据与自动返修资格。

验证使用隔离数据与模拟模型，覆盖合约、真实业务返修边界、旧行为和重启保护；不代表真实创作质量已通过。
