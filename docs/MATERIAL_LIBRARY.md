# 人物、场景与画风素材库

工作室导航的“统一素材库”保存可跨剧复用的人物、场景、画风及组合参考。项目的“素材与定稿”页同时显示统一素材和本剧素材；相同 `series_key` 的各集共用剧内库，独立单集使用自己的库。已有“系列资产”入口及其引用继续有效。

## 从素材到正式制作

1. 新建项目时勾选“先准备人物、场景与画风，再开始制作”。项目保持暂停，worker 不会抢先编剧。也可先创建统一素材，再在已有项目暂停后选用。
2. 新建素材，填写名称与设定，上传 PNG/JPEG/WebP。单张限制为 8 MiB、64–4096 像素，可逐次添加最多16张视图。每次修改追加版本，旧图和已定稿版本不会覆盖。
3. 人物填不变身份/外观与默认衣装；场景说明基础空间结构；画风填通用视觉规则。服装、表情、动作、昼夜、持物等剧情状态可变化，不作为身份变更。
4. 选入本剧时，将人物关联到制作规格中的稳定角色；同名人物不会自动合并。场景、组合可指定适用镜头，或交给分镜依据定稿设定关联。
5. 选择共同画风，点击“按共同画风准备全剧造型”。AI 以现有图片转换人物/场景；没有图片则从设定生成。任务完成后点击“将完成造型加入待定稿”，检查候选，再确认本批。画风转换形成独立剧内素材，来源仍可追溯。
6. 全剧定稿后点击“开始 / 恢复制作”。编剧读取固定的人物/场景设定；分镜关联场景/组合；首帧生成读取参考图片；后续视频继续以首帧和素材回执为依据。

在项目中编辑统一素材会先建立剧内副本。剧内更改不会回写统一库；需要复用时明确“保存到统一库”。组合引用的私有人物/场景需要先保存对应统一版本并更新组合引用，不能隐式发布私有依赖。

## AI 与多人同框

“AI 识图建档”输出可编辑草稿，需要点击采用并保存；不会自动改变人物身份。也可以直接按文字生成或补充人物三视图。补视图和换画风都是生成候选，不代表模型准确还原了不可见的真实细节。

组合参考记录人物素材版本、稳定角色和场景版本。上传同框图片并保存后，再编辑组合、选择人物、点击“框选此人物”，在图片上拖动区域；区域采用0–1归一化坐标。也可直接根据已选人物和场景生成组合候选。定稿前先确认组合引用的人物/场景；集中确认会先处理这些依赖。

模型参考数量以实际适配器/工作流为准：内置 FLUX.2 klein 按4张控制；百炼适配器按具体配置模型限制；自定义工作流槽位必须精确匹配。素材组合任务超限时逐步组合，保留每步回执；正式镜头若仍超限，会在提交前提示准备并确认组合参考，不会丢弃人物图片。专用 Wkp GPU 服务继续使用固定允许图；自定义模板使用已配置的外部 ComfyUI。

生成素材独立检查人物身份、画风、场景及多人对应。技术检查只判断图片解码、尺寸等指标。视觉模型不可用或不能确认时显示实际状态；人工可以检查并确认未获得 AI 结论的候选，明确视觉审核失败的候选需修改或重新生成。

## 任务、费用与版本

素材任务由既有 singleton worker 消费，在没有短剧项目时也可创建；关闭页面不会丢失队列。图像生成复用已配置的图像连接，识图/视觉审核使用支持图片输入的 `visual_critic` 连接。不会安装模型，也不会把 Wkp 能力误配为开发机本地模型。

百炼图片批次先展示最大提交次数及估价，明确授权后才提交。价格未知时需要单独接受未知价格；估价不是供应商账单上限。每次付费 POST 前持久化生成意图；已保存响应可继续下载，结果不确定的 POST 即使恢复任务也不会重投。需要核对供应商记录；修改输入并新建任务代表新请求，并需要新授权。公共任务信息不暴露密钥、私有配置或签名下载 URL。

项目确认的是固定版本，不自动跟随素材库最新版本。修改后先查看“采用此版的影响范围”，再选入并确认；仅相关镜头及其传递依赖进入新制作版本，旧素材与累计费用保留。运行中的项目须先暂停，未核对的云任务不能用换图绕过。

素材与生成回执保存在隔离的 `production/` 目录，元数据、任务归属及授权位于现有 SQLite，沿用完整实例备份/恢复。备份报告纳入未解决的素材云请求；恢复不会自动启动生成。素材、数据库、密钥及生成图片不进入 Git。

本地测试使用独立 SQLite、合成图片和模拟服务。Wkp 的真实身份保持、跨画风和多人同框效果需要已有授权身份联调，不能用本地测试代替。

多图保存中途失败时，已保存的视图继续保留，编辑器显示剩余待上传图片及当前版本。可移除或替换失败文件，再次保存只处理未完成部分。点击参考图可放大检查和下载原图；本剧选择与定稿读取失败时可分别重试。项目角色以服务端制作规格为准，已确认素材变化后旧 Agent 执行归入历史。
