本分支只集成最新 main 与工作包 8，不包含工作包 7 的未合并代码。PR #8 的 CI 成功是该 HTTP 分支的证据，不能冒充本分支或整个下一轮集成成功。

## 优化 8 的实际验证范围

临时 SQLite 的只读事务、并发 WAL 写者、不可变 JSON 快照、缺失和错误回执、独立报告目录、报告中断与完整性校验均有自动测试。三种现有规格使用真实 FFmpeg/PyAV 解码的 CPU 合成片段、正弦测试音频、分段 SRT 和模拟人工记录。只验证代码与文件契约，不代表 TTS、GPU 或云端模型质量。

| 不变量 | 本工作包的措施和证据 |
| --- | --- |
| 未知云 POST 不重复提交 | 验收只读项目和云任务证据；不调用提交/轮询/恢复；原云任务与预算测试保留 |
| 费用账本是权威来源 | 未新增费用账本；SQLite 项目与云任务在同一只读快照读取；并发 WAL 测试验证旧版本证据不混入新任务状态 |
| 项目、已批准素材与成片不覆盖 | 生产目录验收前后全文件校验一致；输出只写独立非 production 目录 |
| 无关镜头不因验收失效 | 不更新项目、不调用缓存失效或 worker；按只读回执逐镜出证据 |
| 当前配置不补造历史模型身份 | 仅使用现有调用记录，缺失配置/模型版本为 unknown |
| 系列参考和人工审片不能被静默替代 | 不变更绑定；没有媒体绑定的人工证据仍要求审片，模拟人工作品不等于真实审片 |
| 模型未运行不能自动通过 | 默认 ASR/VLM/VBench/human 明确 not_run；只导入已有外部报告，生成模型执行仍 not_run |
| 改剪辑参数不重生成视频 | 验收不生成或重剪；时间线升级和复杂 source_range reedit 不属于本次新增能力 |
| 旧记录保持可读、比较不造假 | 历史专项报告可读但不可作为兼容评分基线；检查新增/移除和版本不兼容都有明确结果 |
| 前端旧状态不能覆盖新项目 | 未改变 HTTP 或 CAS；完整 Node/工作台浏览器回归独立运行 |

具体命令、通过数量、失败前证据和 CI 状态记录于 [NEXT_ROUND_PR_REPORT.md](NEXT_ROUND_PR_REPORT.md)。
