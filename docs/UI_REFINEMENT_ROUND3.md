# UI 三轮调整：单一页头与服务概览

继续关联 #51 / PR #52，PR 比较基线保持 #50 的 `codex/provider-connection-cards`，本轮增量从 `80875ad` 开始。服务器发布使用独立集成分支，保留 #48 的现有审核修复；不合并 GitHub PR，不更改 API、模型配置、审核规则或项目数据。

## 最终界面

全站共享 `PageHeader`：标题、业务操作和主题/同步/刷新位于同一区域，取消独立“工作室 / 当前页”顶栏。项目标题旁使用真实返回项目列表按钮，状态入口、作品和下载沿用原操作。窄于768px时，主题、同步和刷新归入“页面工具”，导航按钮留在标题旁。加载、失败及空数据也保留页头。项目内素材区域使用二级标题，避免重复页面标题与工具。项目业务操作横排，清除旧竖排及全局details外距；展开项目操作菜单也不推动标题、导航与内容。

主题状态由应用根部 `ThemeProvider` 保存。切页、工具开关和窗口变化不会重置会话偏好；保留原 `studio.theme` 三值、系统跟随、跨标签同步及存储不可用时的选择。工具支持键盘、Esc关闭、失焦/点击外部关闭及焦点恢复；原通知与状态抽屉保持覆盖页面，不新增会挤动导航的提醒条。

模型连接按原 `services(draft)` 分组形成卡片，不按供应商图标合并：URL、凭据或TLS不同的连接保持区分。卡片展示用途、供应商、模型摘要和地址；配置按钮直接进入原编辑器，模型数量打开覆盖式详情抽屉，承载完整模型、协议、凭据关联、文档和逐模型检查。抽屉桌面480px、手机全宽。服务已配置、停用和手动连接检查结果分别表达，不自动探测。

卡片按内容容器宽度排布：小于640px一列，640–979px两列，980px及以上三列。桌面页签、搜索和添加服务同排；手机页签下一行为搜索及添加服务，无内部服务侧栏或常驻空详情区。

## 色彩与状态

主体保持黑白灰与一种蓝色强调，官方Logo和作品保留原色。新增独立 `--status-*` 变量和共享 `StatusIndicator`，只对约6px小点及必要的工作流细线使用颜色：执行蓝、人工审核琥珀、明确失败红、通过绿、未开始/停用/未验证灰。原成功、警告、失败背景变量继续保持中性，避免重新染满卡片。状态文字始终保留，未知值不推断为成功或审核中。

## 验证与证据

使用独立 fixtures、临时数据库及合成媒体，不访问真实模型生成。17个视图在320、390、768、1024、1440、1920宽度和浅深主题检查单一页头、导航、操作、内容宽度及配色；另覆盖系统主题、跨标签、存储失效、错误与抽屉稳定性、连接与分工、未保存草稿、版本选择、证据、旧链接与下载。

修改前后截图及量化结果见[三轮截图](images/ui-refinement-round3/README.md)。生产服务器验收另行记录于 PR，只读访问真实入口；配置、项目快照、队列、视频和生产元数据哈希核对与回退点保留在服务器私有运行目录，未提交仓库。

最终源码 `de8de00` 的本地验证：265项UI单测、1749项Python契约测试通过（4条既有multiprocessing弃用警告），类型检查、生产构建及依赖许可归档通过。最终完整Chromium回归126/126通过，未跳过、未重试；桌面同行、菜单展开锚点和同步异常5项先行检查也通过。开发期间发现的旧刷新/标题定位已更新，并修复项目操作继承details外距导致的14px偏移；最终全量结果不含遗留失败。

模型首卡在1440×1000为141px，390×1000为199px，320×1000为203px；内容宽度639/640/979/980px精确对应1/2/2/3列。320/390/1440视口下错误、轮询和状态抽屉的测量锚点最大位移0px；项目操作菜单开关在桌面矩阵中也满足不超过1px。工作流执行、待人工处理、阻断、完成分别使用既有fixtures实际节点，两主题共8个场景验证6px状态点和中性主体。
