# UI 二轮收敛：稳定布局与统一视觉层级

继续关联 #51 / PR #52，比较基线为本 PR 上一版 `2765018`；前置仍为模型连接 PR #50。发布时保留现有 PR #48 审核修复，不改变后台 API、模型参数或审核规则。

## 问题与最终行为

上一版项目阻断提醒按页签插入导航上方，同一项目切换概览、剧本时导航会移动约 84px。现在项目标题旁始终提供“查看项目状态”入口；长期问题、影响镜头和既有处理入口进入覆盖式详情抽屉，不再推开导航。桌面抽屉宽400px，手机占满视口；使用现有原生dialog，保留Esc关闭、焦点恢复与滚动锁。稳定滚动条预留空间和抽屉边缘补偿共同避免横向位移。

页面请求失败和操作反馈进入同一固定通知区域，重复的同文错误合并；关闭后同一次连续错误不重复弹出，成功恢复后再次失败可以重新提示。普通成功反馈沿用7秒，错误保持到恢复或手动关闭。手机通知位于下方，给标题和底部保存操作保留空间。表单校验和保存错误留在表单，固定64px反馈区避免挤动操作；长错误可打开详情并返回原焦点，未保存输入继续保留。镜头编辑错误放在编辑表单，选片失败使用通知，正常预览不预留空白错误区域。

全站界面使用中性黑白灰和单一蓝色强调。成功、警告、错误保留业务语义，视觉统一为中性文字、图标与边框；蓝色用于链接、焦点、选中指示。官方Logo和实际图片、视频保留原色。主要按钮为黑白反差，不新增配色设置。

## 回归中修复的交互问题

团队介入弹窗的复选框曾在一次点击后短暂恢复旧值，再等待异步查询通知更新，造成约35ms的状态回退。草稿仍存原查询缓存，改用同步外部存储订阅读取，避免受控表单恢复过时值；缓存键、草稿恢复、API和权限检查保持原有行为。新增同步点击及重新打开保留选择的单测，原浏览器操作断言继续执行。

错误详情嵌套在表单弹窗时，Escape只关闭最内层详情；阻止取消事件冒泡，保持父表单、未保存输入与原焦点。

## 验证与边界

- 独立fixtures覆盖状态抽屉、错误去重/恢复、表单详情、输入与焦点保留，以及标题/导航/内容锚点在错误和抽屉开关前后位移不超过1px。
- 完整浏览器回归包括7个全局视图、10个项目页、浅深主题和320/390/768/1024/1440/1920宽度，并保留旧hash、浏览器历史、草稿、选片、证据和下载操作。
- 测试媒体是合成色条，模型为fixtures；真实Python HTTP测试使用临时数据库，不代表真实模型生成质量。
- 截图见[二轮对比证据](images/ui-refinement-round2/README.md)。服务器只读验收和发布提交单独记录于PR，不以本机预览代替服务器更新。

本地验证：222项UI单测、1749项Python契约测试通过；类型检查及生产构建通过。完整浏览器回归116项通过；最后的嵌套Escape隔离修改及新增场景，再执行反馈/主题/模型表单26项受影响浏览器回归，全部通过。没有降低原功能断言；旧消息定位和固定390px假设改为新浮层定位及滚动锁前后宽度稳定检查。
