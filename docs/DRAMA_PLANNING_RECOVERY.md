# 整剧规划返修与下一步（0.2.4）

新建整剧后先完成设定、分集大纲和独立审核，再确认规划、选择剧集及制作预算。规划暂停时还没有视频任务，等待或反复刷新不会继续。

## 页面操作

- 在总览或制作页的“制作下一步”中点击“查看问题并修复规划”，进入全剧规划。
- 查看本轮问题及草稿；可以填写最多4000字的本轮补充要求，再点击“修复规划并继续”。需求随项目保存，原来的集数、每集时长和创作方向保留。
- 手工编辑下方规划时，自动返修入口会禁用并提供“前往提交规划修改”，避免覆盖尚未提交的编辑。提交失败会保留补充要求，重试沿用同一操作标识。
- 审核通过后检查并确认规划，再点击“选择剧集并设置预算”。制作任务及成片继续使用既有授权、暂停恢复和验收流程。

## 返修处理

每轮先检查规划合约，再交独立审稿。角色ID或名称冲突、非法角色引用、前向依赖、分集重复及只有相同起止状态而没有剧情的候选，会形成有目标的返修问题，保存稿件与记录。针对后续分集的合约问题会复用设定和未受影响的前集；从修改集开始重新接续后续大纲。设定问题与整体语义审核仍按对应职责返修。

每次编剧请求的schema固定当前集号、允许引用的角色及前集依赖范围，并单独列出本集任务与前集结尾。审稿参数明确区分每集时长和全剧总时长，说明剧情承接与制作依赖的区别；前集结尾与后集开场一致本身不构成剧情重复。合约检查不能批准作品，技术合格的候选仍须独立审核。

每轮审核记录绑定稿件哈希。有界返修仍为3轮，达到上限后保留全部草稿并等待明确操作。旧项目因非法依赖停在审核阶段时，再次处理会带上该稿的诊断开启新轮次；服务异常的暂停恢复则保留当前轮次与已完成调用。补充要求改变时进入新轮次，避免套用旧缓存。

## 验证证据

自动验证覆盖身份/分集重复、空转大纲、非法依赖、原生集号约束、定向复用、暂停恢复、历史坏稿恢复、补充要求、CAS/幂等、独立审核及停止边界。浏览器用匿名合成项目检查桌面和手机、明暗模式下的修复、失败重试、手工编辑保护、确认和选集入口。

真实验证使用用户选择的2集、每集120秒需求及既有Qwen调用配置的隔离副本。保留了初次验证仍耗尽3轮的失败样本；修正任务集号约束、承接参数和审核依据后，后一次验证经4次岗位调用、约39秒进入待确认规划。该证据仅证明本次规划可以推进，成片质量需实际媒体生成与独立审核验证。原项目和素材在隔离验证期间保留。
