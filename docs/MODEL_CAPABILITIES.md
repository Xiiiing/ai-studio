# 模型能力与提交前校验（0.3.8）

模型目录的 `model_capabilities` 和 `model_capability_presets` 保存现有图像、视频和语音适配器的能力。服务设置页从同一份数据展示参考数量、首尾帧、时长、画布和未知项；MiniMax 的时长与清晰度选项也由它生成，不兼容组合不能保存。能力来自仓库适配器或内容寻址的自定义工作流映射，不代表供应商实际可用、模型效果、连接探测或真实生成已验证。

## 新项目与历史项目

新项目固定 `model_capability_snapshot`，剧集和制作单元继承父项目快照。正在运行的项目不自动跟随全局配置更新。历史项目没有该字段时沿用旧调用合约，不因打开页面而补写快照；显式启用或更新能力版本必须在既有空闲、版本校验及未知请求对账边界执行。采用后只重新检查能力，不自动修改剧情、生成素材或费用授权。

连接身份、模板映射或能力版本变化后，新制作需要重新明确应用能力；密钥变量和地址不写入能力快照。所有新快照沿用项目 SQLite 持久化、备份和恢复。素材 AI 任务保存自己的能力快照，旧任务继续读取原记录。

## 在项目中显式采用

项目的模型能力面板读取服务端记录的当前快照、历史快照与可操作状态。先暂停并核对在途／未知请求，再勾选保留已有成果并采用能力的确认项。旧项目显示“启用本项目能力校验”，已有快照的项目显示“更新本项目能力版本”。这项操作不生成、不授权费用、不批准素材或成片。

确认固定到当时的项目版本；项目刷新出新版本后需要重新确认。响应中断时保留同一操作，可重试或刷新核对后重新准备。面板不以今天的全局配置补写旧能力，也不把查看页面当作启用。

## 提交边界

启用本合约的制作在分配新生成尝试前检查一次，在实际上传或请求前按最终提示词和参考素材再检查一次。失败返回 `model_capability` 和明确字段，不上传参考、不创建新生成请求，也不会消耗新生成尝试。每次实际尝试保存所校验能力的版本和身份。

- Wkp H3 的本适配器只实现一张首帧、24fps、1–15秒及已有有界画布，不因其他 H3 协议支持尾帧、多参考或音频而开放这些选项。
- Qwen-Image-2.1 使用已有0–4张参考、256–1536像素／32像素步长和画布像素上限；FLUX内置路线使用已有0–4参考合约。
- 百炼按当前模型系列的适配器参考上限检查。新合约下，小于适配器最低像素数的请求明确拒绝，不能静默扩大生成尺寸；旧任务保持原有规格解释。
- MiniMax视频按已配置的生成时长与清晰度组合检查；用于剪辑的镜头时长不能超过生成时长。实际首帧文件继续检查大小、格式及比例，不以浏览器声明代替像素读取。
- 云视频返修需要重制首帧时，也先检查项目固定的图片能力与完整参考集；超限、图片连接停用或快照不匹配时停止，不截掉多余参考图。恢复中的视频请求在准备返修和费用意图前重新检查。
- 自定义工作流精确匹配参考槽位，并须映射制作所需的宽高，视频还须映射帧数和帧率；缺少映射时不假定请求参数已经生效。供应商模型约束和自定义图的语义仍明确列为未知。
- 语音校验已有正文与声线映射／明确默认声线；实际声音时长仍由原配音测量与制作审核判断。

分镜生成流水线使用相同快照作为能力上下文。能力检查与实际媒体技术／语义审核分别记录，配置通过不能替代成片审核。

## 验证

`tests/test_factory_model_capabilities.py` 覆盖共享目录、冻结／显式更新、未知适配器、真实文件、参考数量、时长／清晰度矩阵、工作流映射，以及真实新尝试、云视频首帧返修与恢复入口的零调用阻断。UI用例覆盖能力显示、后端选项、显式保存和不兼容组合。相关既有制作、素材、外部工作流、云媒体及视频测试继续运行。

本阶段验证使用独立配置、合成媒体和模拟传输，不调用真实模型，不证明供应商或作品质量。
