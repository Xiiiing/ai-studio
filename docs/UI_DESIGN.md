# 工作台 UI 设计与兼容约定

工作台采用大面积白黑中性色、适量可选低饱和主题色和少量必要语义色。该约定覆盖全局视图、项目页面、共享弹窗及明暗主题；整剧流程与自动返修规则见[整剧制作](DRAMA_PRODUCTION.md)。

## 视觉与交互

- 白黑用于页面、面板、大卡片及正文；主题色用于主按钮、项目内选中项、关键操作与进度；全局主导航使用黑白选中态。失败/紧急用红，待处理问题用黄，通过用绿，限于有意义的标签、图标、细边和局部提示，不铺满大卡片。中性与语义颜色由`styles/tokens.css`定义，主题色由`styles/accents.css`覆盖，并配合文字标明状态；明暗主题正文和按钮满足AA对比度。供应商官方Logo与实际素材保持原色。
- 品牌统一使用 README 已有的[电影画框与金色星芒 Logo](assets/logo.svg)，保留原图形与原色。`ui/factory/public/brand.svg`是该资产的完整副本，单测校验逐字一致；更新原资产时同步复制，侧栏`BrandMark`与浏览器图标均引用该副本。移除英文装饰副标题、侧栏重复底座和宣传页脚；流程阶段显示中文，保留影响操作的预算、审核问题、来源和版本提示。
- 每页保留一个主标题和明确操作区，移除英文装饰标题与无功能头像。柔和渐变限于总览的项目焦点区，表单、数据卡和工作区维持中性色。相同信息不在概览重复堆叠；详情通过分组或展开查看。
- 主题按钮以显示器、太阳、月亮表示当前偏好，按 system → light → dark → system 循环。悬停和聚焦说明当前与下一模式；原 `studio.theme` 值、系统变化跟随与跨标签同步保留。存储不可用时仍支持本次会话切换，初始化脚本在样式渲染前应用主题。
- 正常同步状态为小型指示，异常保留明确文字；图标操作提供可访问名称，所有业务决定保留文字、确认与版本检查。项目状态入口常驻标题旁，长期问题按需打开详情抽屉；请求失败与临时反馈使用固定通知区域，不插入导航上方。表单保留就近错误和草稿，长错误可查看详情。

文字层级及反馈交互沿用[UI二轮收敛](UI_REFINEMENT_ROUND2.md)，颜色与自有品牌以本页为准。

## 参考图与设计模型

本轮依据用户提供的三张后台界面参考图提炼设计方法。图中相近的卡片语言、浅色画布、黑白导航与局部绿色焦点共同构成层级；能源设备图和统计图服务于各自业务。本应用将其转为影视制作语境，保留既有五项导航、六款主题和真实制作流程。

| 设计方法 | 参考图表现 | 在映序中的实现 |
| --- | --- | --- |
| 画布、容器、内容三级 | 浅灰外底、浮动圆角工作区、白色内容卡 | 桌面圆角外框、轻边与低阴影，统一16px内容卡；手机使用全宽空间 |
| 视觉权重分配 | 标题、主数据、辅助文字有明显尺寸差 | 当前项目标题优先，四项真实制作指标用大数字，事件和资源作为次级内容 |
| 同组靠近、同类一致 | 模块对齐，卡片间距与内边距有规律 | 统一间距与控件圆角，任务与待办组成主区域，动态与资源置于其后；项目、模型与流程共用面板语言 |
| 少量强调色 | 黑白承担大面积信息，少数绿色卡片吸引注意 | 主导航采用黑白选中态，主题色用于焦点卡、操作和工作流节点；六款主题均可切换，语义红黄绿保持独立 |
| 图形表达业务 | 财务图表与能源设备场景 | 用三张胶片卡表达制作内容，有合法项目首帧时展示已有图像；GPU条与项目进度来自真实回执，不生成虚构曲线或节省时长 |
| 操作与内容相连 | 焦点模块有明确出口 | 总览优先选择待处理项目，其次执行中、未完成及最近项目；“打开当前项目”进入服务端指定的待处理阶段。无项目时提供“新建一部剧” |

胶片叠卡只承担装饰，不包含可聚焦控件，手机隐藏以优先保留文字和操作。项目标题完整换行，按钮保持44px触达；已有图片加载失败时回到胶片图标。外观是界面层更新，不改变模型、角色、审核或生成配置。

实现集中在`styles/studio-design.css`，通过既有主题token派生边框和轻背景；不引入新的设计组件依赖。关键行为和六款配色保持原检查，增加真实焦点选择、空态创建、长中文标题、装饰遮挡、明暗及桌面/手机检查。[本轮界面与复现](images/studio-design/README.md)。

## 外观设置

页面右上角“外观设置”图标打开`#view=settings`；手机先展开“页面工具”。外观设置独立提供显示模式（跟随系统、浅色、深色）与六款主题色。点选即时应用到全局按钮、项目内选中项、焦点、进度和工作流选中态；页面展示真实主题 token 的效果预览，无需保存按钮。设置页不依赖业务API可用性，也不写入模型、项目或服务器配置。

| 主题 | 浅色模式主色 | 视觉方向 |
| --- | --- | --- |
| 深灰蓝 | `#46566e` | 保留既有默认色 |
| 石墨 | `#53545b` | 中性灰 |
| 青瓷 | `#3e686b` | 灰青 |
| 松绿 | `#4b6656` | 灰绿 |
| 暮紫 | `#675b7b` | 灰紫 |
| 暖铜 | `#785c47` | 棕铜 |

配色参考[Radix配色组合](https://www.radix-ui.com/colors/docs/palette-composition/composing-a-palette)和[色阶用途](https://www.radix-ui.com/colors/docs/palette-composition/understanding-the-scale)，将浅选中背景、实底操作、悬停、文字及焦点分别定义；这些是本应用自定义低饱和色阶，并非直接使用Radix原始色值。六套均有独立深色配色，切换不改变白黑主体、红黄绿语义状态和README原Logo。

显示模式沿用`studio.theme`，主题色单独保存在当前浏览器的`studio.accent`，以白名单校验；无效值回到深灰蓝。偏好不跨设备同步，同源标签页通过storage事件同步。存储不可用时本次会话仍可切换；由根Provider保留会话状态，页面切换不重置。`theme-init.js`从构建静态路径在首屏加载前应用两项偏好，避免依赖React挂载后才恢复颜色。

单测校验六套配色在明暗模式下主按钮、悬停、主题文字和焦点对比度，浏览器实际检查六款切换、键盘选择、刷新恢复、跨页与跨标签同步、首屏脚本、API不可用和手机布局。[设置页截图与复现](images/appearance/README.md)。

## 导航与内容

侧栏采用扁平导航，按顺序仅显示总览、项目、素材库、运行记录、模型配置，不再显示“工作室／管理”分组及全局“流程与团队”入口；近期项目仍可直接访问。模型页使用“模型配置”名称，模型地址、角色分工和工作流定义不因导航调整而改变。

待办集中在总览，直接进入对应项目及需处理阶段。完整列表沿用独立待办分页查询，每页最多100项，不限于最近项目；分页失败可就近点击“重新读取待办”，错误仍通过统一反馈区显示。旧`#view=inbox`链接显示总览，旧`#view=workflow`显示项目列表；保留原地址及浏览器历史。具体项目里的工作流、团队和执行回执入口继续使用。

| 主入口 | 原 hash 与子页面 |
| --- | --- |
| 概览 | `overview`：作品、当前问题与下一步；进度和预算为摘要，流程/团队/背景和事件按需展开 |
| 剧本 | `script`：正文、人物与逐镜分镜 |
| 素材 | `materials` 项目素材与定稿；`series` 系列资产 |
| 镜头 | `shots`：当前视频与首帧、审核结论、紧凑版本记录与单镜精修 |
| 审核 | `decisions` 待办决策；`quality` 质检记录 |
| 交付 | `delivery`：现有成片播放与下载 |
| 更多 | `team` 团队回执；`costs` 云任务与费用 |

旧 hash、前进后退与深链接不重写。主页面和子页面各自明确选中状态；窄屏保留六个主入口与更多，不使用第二层竖向侧栏。

镜头预览默认每种素材显示一个版本：已选定版本优先，其次当前参数下可预览素材，再次历史可预览素材。历史预览有来源提示；如果当前参数的新版本审核尚未完成或失败，会另列当前参数结论。历史转为紧凑列表，用户显式选取两个版本后比较，不触发生成或保存。选片仍要求确认、可选资格和原版本检查。

模型服务以用途、供应商/模型与地址区分；连接和制作分工保持独立。模型 ID、协议、上下文、密钥关联与 TLS 能力由现有接口提供，不根据 Logo 推断。完整参数和原始回执按需展开。

## 验证与证据

- UI 单测覆盖主题、旧路由、审核阶段显示、版本对比、待审核与失败区分、播放 DOM 保持及选片修订保护。
- 浏览器覆盖全部5个主导航页面、外观设置、旧全局链接及10个项目页面，浅深两套主题及320/390/768/1024/1440/1920宽度，检查溢出、按钮可达、旧链接与历史、草稿、表单保存和作品下载。
- 交互使用独立 fixtures 与独立临时 SQLite；真实 HTTP 测试使用测试 Python 服务。色条媒体、模拟模型与审核数据均为测试材料，不是模型推理或制作质量验收。
- 本次验收不操作正式项目，不调用真实生成，不自动合并或部署。历史截图见[UI改造证据](images/ui-unification/README.md)，当前配色、品牌和审核返修界面见[本轮证据](images/review-return/README.md)。
