# 参考图的定向返修（0.2.6）

共享人物、场景、道具及组合参考图同样需要技术检查和独立视觉审核。模型返回的缺失物体或状态冲突应落实为下一次实际生成请求中的修正，而不是仅更换随机种子再次抽取。

无逐镜`shot`的图像目标，返修依据来自已经批准的当前目标提示词及参考图用途。参考图保持人物身份、场地或道具本身的用途，不借返修添加故事动作；修正指令强调已要求的服装、随身物体、外形和空间关系清楚可见。实际发出的提示词及依据沿用现有attempt记录保存。

审核描述错误画面的自由文本保留作诊断，不能直接复制为正向生成指令。技术错误、逐镜静态首帧与视频动作继续遵守各自原有合约；返修不会自行扩大授权、改变剧情或覆盖审核结论。所有生成仍须重新通过独立审核，原候选和已通过素材保留。

暂停恢复时，已提交推理任务先按原请求标识对账并读取结果；修复只作用于之后真正需要的新尝试。提交结果未知时不能换标识重投。未通过的样本可以用于排查，但不能被当作已批准参考图或成片质量证据。

配置变化时，GPU提交日志先交给持久化推理服务对账，再检查外部ComfyUI日志。远端已完成但本地仍为running的请求按原标识写回终态并累计一次计费；仍在运行、身份不匹配或缺少计费回执时继续阻止新提交。外部ComfyUI未知结果保护和同源任务恢复保持不变。

共享参考图在首次生成前，以完整姓名、批准身份、衣装及明确关联道具编译静态图像提示词。编译缓存包含原事实、模型、提示词快照和图像适配器身份，原事实与候选分别留档。审核独立读取原事实及实际提供的图片数量；没有对照图时不得假想原作或参考图片进行身份比较。参考素材按自身用途检查，不要求表演后续镜头动作。已批准共享素材继续复用。

参考图问题包含额外要求、无依据比对或低分时，独立质检使用同一候选像素再做一次证据复核。每个旧问题保留编号；确认问题须引用批准事实的编号及原文，推翻问题也须重新观察实际图片并说明原因。复核不能由创作者覆盖，确有依据的问题继续阻断；不确定、依据伪造、复核超限或调用失败时保留原图待补审，不据此继续抽图。原审、复核、事实和像素身份均留档。参考图审核策略变化只使审核签名失效，技术合格的既有失败候选可原图重审，不重置生成额度。
