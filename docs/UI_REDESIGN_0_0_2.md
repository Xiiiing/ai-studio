# 0.0.2 工作台主题与多屏体验

本次迭代覆盖七个工作室页面、十个项目页面和公共弹窗、表单、文档及媒体预览。保留映序品牌与真实制作工作流，以中性灰阶和蓝紫强调色统一浅深主题，优先展示当前状态、下一步与作品。

## 使用变化

- 顶栏选择跟随系统、浅色或深色外观。浏览器记住选择，首屏提前应用主题；跟随系统时实时响应系统变化。
- 桌面项目内容按创作与流程、视觉与制作、协作与交付分组。平板和手机点击当前页面名称展开十个入口；全局导航使用可关闭的抽屉。
- 手机点击制作阶段进入详情，返回后保留当前阶段。桌面流程与详情并列，详情独立滚动；主动切换步骤回到标题，自动刷新保留阅读位置。
- 项目搜索覆盖名称、编号和需求的全部记录，先筛选再分页；输入防抖期间暂停翻页，避免把旧页码带入新搜索。
- 模型和逐镜草稿在本次页面会话中跨页面保留，绑定编辑时的版本。保存期间锁定编辑，失败保留输入；版本变化后明确要求核对，不覆盖其他终端的更新。
- 连接检测显示卡片内结果和进行中状态；配置修改后旧结果失效。首次读取失败显示重试入口，刷新失败仍保留已有内容与正在播放的视频。
- 素材卡片显示版本、角色、选用和定稿状态，次要操作按需展开。框选提供实时区域、当前人物、取消、清除及可键盘输入的归一化坐标；识图草稿直接保存也会实际建立新版本。
- 模型、素材页面和 Markdown 排版按需加载。首屏主 JS 包从基线 588.12 kB 降至约 388 kB，Markdown 排版独立为 159.26 kB；局部加载保留项目导航、原文和放大阅读状态。

## 实现边界

外观选择保存在 `studio.theme`；配置和逐镜草稿仅保存在应用内存，不把私有配置写入浏览器持久存储。刷新或关闭页面前提醒未保存内容；未加入待保存修改的临时连接弹窗仍采用原有的确认编辑方式。

保留页面地址、业务动作、固定素材版本、审核意见、费用授权、CAS 校验和模型执行语义。扩展总览查询的 `q` / `filter` 参数，格式见 [API 文档](API.md)。无数据库迁移，独立的后端版本号保持原值。

样式按语义变量、共享组件、页面、工作流与断点组织。键盘导航、弹窗标题与焦点恢复、减少动态效果、手机触控尺寸和关键文字对比度均纳入浏览器检查；不将本次验证表述为外部无障碍认证。

## 本地验证

- Python：`tests/test_factory_*.py` 共 **1458 项通过**；其中总览搜索、控制台及动作相关检查 **126 项通过**。
- UI：**148 项通过**；类型检查与生产构建通过。
- 完整 Chromium：**70 项通过**。覆盖主题首屏与持久化、系统变化、键盘和焦点、减少动态效果、草稿、保存并发、检测、审核镜头定位、超过 100 个项目搜索及真实指针框选与保存。
- 320 / 390 / 768 / 1024 / 1440 / 1920px，浅深主题分别检查全部 17 个页面，共 **204 个组合**；检查页面溢出、导航可达与触控目标，并生成全部截图。已人工检查页面缩略图与桌面、手机、文档、素材原图及模型配置的代表性大图。

浏览器证据位于忽略的 `runtime/browser-report/`，CI 通过 `browser-smoke-evidence` 上传。测试仅使用公共示例配置、临时 SQLite、隔离 HTTP、CPU 合成媒体和模拟提供商，不加载生产凭据、不启动 worker、不调用模型或收费接口。

第一阶段主题与公共交互基础独立验证 **129 项 UI、46 项浏览器通过**；第二阶段包含页面、编辑和恢复操作，按功能保留独立 commits。完整需求关联 [Issue #31](https://github.com/Xiiiing/ai-studio/issues/31)，第一阶段为 [PR #33](https://github.com/Xiiiing/ai-studio/pull/33)。第二阶段依赖第一阶段，合并时通过 `Closes #31` 关联总需求。

本次没有部署、迁移生产数据或验证 Wkp 上的实际模型推理与生成品质。
