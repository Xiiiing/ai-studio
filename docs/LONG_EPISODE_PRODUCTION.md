# 长集场景规划与真实制作（0.2.5）

91–900秒的剧集先拆成顺序场景，再按最长90秒制作单元运行现有执行图，生成并检查图片、动作视频及声音，最后拼接单集。第二集的既定依赖在第一集产出待验收视频后自动接续，无需先人工批准第一集。

## 固定片长与独立审核

场景编剧和独立审核共享单集时长合约，包含目标总秒数、最短场景时长与最多场景数。审核同时读取世界、关系、人物、已知地点/道具、前集承接和固定开结尾；系统提供逐场时长及实际总和。

审核对象是当前场景大纲。必要动作过密、因果缺口或道具状态矛盾仍须返修，问题需要指向具体场景、字段与文本依据，并在固定片长内通过简化或重排落实。没有提供的对白、可选停顿或表演偏好不能被当作既定内容，再以此要求增加片长。实际视频仍须经过媒体检查与独立审核，场景审核通过不能替代成片证据。

编剧返修会拿到上轮候选、技术诊断及独立审核意见。总时长错误明确记录实际、目标及差额，避免仅看到“总和不等”而不知如何修复。三轮上限保持不变，所有候选、版本哈希、技术检查与独立审核记录保留；暂停恢复复用已经完成的当前版本检查。

## 自动化边界

当前`delegated`团队能处理故事/视觉选择和图内有界返修，长集单元无需逐个人工确认。但项目级预算授权与自动终稿尚未覆盖全流程；达到审核或资源上限仍停止。已有云授权不等于无限收费授权，提交结果未知时不能盲目重投。

出品人明确授权代理继续某个项目后，代理可以沿用现有预算，通过既有业务API执行选择与恢复；这些操作需要记录。代理代为运行不代表应用已具备完整的项目级自动制作授权。实际视频进入`awaiting_final`时即可观看，交付预览不需要伪造人工批准或发布作品。

预算按既有每单元额度执行，场景拆分后展示整集累计授权；用户指定的集数、每集时长和已经确认的设定保持不变。成功单元与素材在恢复时继续复用。
