# 制作质量与剪辑验收（0.3.5—0.3.10）

本轮在已有制作修复与一句话整剧闭环之上，增加审核边界、剧情覆盖、跨镜状态、模型能力、逐镜依据及独立剪辑版本。实现和验证记录分别见 Issue #91—#96；自动验证不等于真实模型效果或用户实测通过。

## 检查入口

| 版本 | 入口 | 验收重点 |
| --- | --- | --- |
| 0.3.5 | 项目审核 → 审核与返修依据 | 展开问题的类别、位置、来源、影响与修订目标；审美建议不能单独引起自动重写。 |
| 0.3.6 | 审核与返修依据 → 剧情覆盖 | 查看原文与事件映射、缺失和独立审核结论；映射完整不显示为实际媒体已通过。 |
| 0.3.7 | 审核与返修依据 → 跨镜状态 | 查看前镜末态、本镜初态、允许变化与实际交界帧复核；正常换场不等于错误。 |
| 0.3.8 | 更多 → 模型能力与版本 | 查看项目固定能力、历史和显式采用入口；忙碌项目不能更新，读取不调用模型。 |
| 0.3.9 | 镜头制作台 | 对比候选，核对来源、参数及采用影响；单镜精修显示传递依赖，无关镜头复用。 |
| 0.3.10 | 时间线剪辑 | 拆分、裁剪、重排、转场、调整音轨与字幕；保存新版本、生成草稿、载入历史，确认新片长。 |

旧项目只在空闲边界显式启用新契约。原始剧本、候选、实际请求、费用、已确认素材及旧成片保留；新剪辑不会继承旧成片的人工通过标记。长剧集在单集内编辑，整剧须先选择具体剧集。

## 自动与真实验证

离线验证使用隔离数据库、合成图样和测试音。实际 HTTP、持久 worker 与 FFmpeg 用于检查版本冲突、恢复、取消、镜头顺序、帧数、转场、音轨及字幕。这些图样不是模型画面，测试音不是人物配音。

独立测试实例可创建带明确标记的 CPU 时间线样例，用来检查保存、预览和历史恢复。未配置独立审核、证据不足或尚未明确授权时，保留草稿，正式导出保持阻断。真实模型验收使用独立的三集、每集60秒匿名样例及本轮明确额度，不复用旧任务的授权或恢复既有暂停项目。

必要检查以 CI 和 package.json 为准：Python 合约、UI 单测、类型/生产构建及真实浏览器。界面需在桌面与390/320像素、明暗主题实际操作；发布时区分模拟、真实 HTTP、合成媒体和真实模型证据。
