# 0.2 系列 Agent 升级路线

用户于 2026-10-19 确认：短剧制作优先，专业模板加高级配置；预算内质量优先自动制作并形成终稿，对外发布单独授权。本次生成提示词可自动尝试改进，公共角色模板经验证和人工确认后启用。

沿用 LangGraph、worker、任务账本、现有模型连接和双环境隔离。[Issue #57](https://github.com/Xiiiing/ai-studio/issues/57) 为总追踪，既有角色交接 [#59](https://github.com/Xiiiing/ai-studio/issues/59) 保持原会话归属及 0.1.7 版本。各独立功能开工时在本地约束中登记不同 0.2.x 版本，不把本路线图视为全部实现或验收。

| 阶段 | 功能与完整交付边界 | 依赖与当前状态 |
|---|---|---|
| 1 | 质量基线与比较台：冻结项目和实际调用证据，分开质量记录、耗时、费用、重试与返修，明确缺口和效果结论未建立。 | 0.2.0，复用 #62；用户实测通过，PR #72 已发布，未合并。 |
| 2 | 提示词工作台：分层装配、编辑、预览、试运行、版本比较/启用/回退；参数化制作规格，保留历史与批准素材。 | 阶段 1；0.2.1，#74；用户实测通过，PR #75 已发布，依赖 #72，未合并。 |
| 3 | 生成提示词流水线：结构化镜头/人物/动作/声音计划，首帧视觉证据，按生成适配器能力编译。 | 阶段 2；0.2.2，#76；独立分支实现和验证，待用户实测，尚未发布 PR。 |
| 4 | 有界 Agent 循环：读取材料、规划、工具、检查、补料、交接，持久化暂停恢复与版本保护。 | 阶段 2、已验收的 #59；尚未实现本轮增量。 |
| 5 | 专业团队配置：岗位、模型、提示词、技能、权限、材料、审核者和额度；模板、预检与项目快照。 | 阶段 4；尚未实现本轮增量。 |
| 6 | 独立审核闭环：具体版本和证据绑定，按责任岗位定向返修，保持未受影响的批准成果。 | 阶段 3、4；尚未实现本轮增量。 |
| 7 | 预算内自动交付：方向/供应商/费用/时间/返修/终稿授权，预算未知、结果未知和无法修复时停止。 | 阶段 5、6；尚未实现本轮增量。 |
| 8 | 有证据的制作经验：来源、适用条件、版本、接受/编辑/停用与范围管理。 | 阶段 6，复用 #60；尚未实现本轮增量。 |

阶段顺序是交付顺序；阶段 4 的角色交接与阶段 6 的返修不重复开发 #59。#61 的集中故障注入以及 #62 的完整可靠性/效果评测在相关能力完成后继续接入，不能以这些后续任务替代每阶段自身必需的恢复、边界和测试。

每阶段按独立目标提交，完成必要自动验证后更新 cami 测试环境，提供用户本机入口、分支、提交及验收步骤；用户实测通过后才发布关联 PR。审核、合并和稳定版发布另行安排。后续功能与已有导航等并行任务使用独立 worktree，不覆盖其他任务的源码或待验收环境。

新接口围绕提示词版本、结构化制作计划、受校验的 Agent 动作/事件、证据绑定的审核问题及项目制作授权扩展；运行项目固定配置快照，旧项目继续原执行版本。必需材料不静默裁剪，原生工具调用与结构化动作执行同一校验规则。

质量比较固定输入、模型、提示词与参数，保留失败/退步样本；故事、画面、动作、声音和整片分别评估。合成协议检查、真实 HTTP、真实模型和服务器验收分别记录。机制参考及既有取舍见 [REFERENCE_ARCHITECTURES.md](REFERENCE_ARCHITECTURES.md)。
