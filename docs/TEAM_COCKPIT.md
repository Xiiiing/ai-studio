# 中文团队指挥台

工作台统一使用 React，在项目内连接 Agent 任务、执行回执、产物、决策与交付检查。旧 UI 已删除，`/legacy` 返回 410；镜头工作台、模型配置和媒体播放保留业务能力。

## 使用

项目首页默认显示五个固定阶段：故事策划、剧本与分镜、视觉确认、镜头与后期、终审交付。点击阶段卡片在右侧查看真实子步骤，窄屏使用上下布局和正常滚动；无需缩放或平移画布。返修单独显示去向，v1 中按需执行的步骤保留条件标记。自动刷新保持手动选择。

步骤详情展示参与模型角色、制作工具和人工决策职责，以及当前业务材料的输入、输出和来源。两侧附件都可在页内阅读，Markdown 正文和 JSON 原文共用阅读器，支持放大、下载及已有音视频预览。文本按需加载，上限 2 MiB；缺失文件可重试，过大文件下载后阅读。

执行记录按保存的调用和重试次数提供请求、响应、解析结果及回执。新调用使用实际步骤运行标识关联；旧调用缺少归属时明确显示为角色历史。团队页中的调用可定位回步骤；当前项目材料不冒充历史调用的输入。原文阅读保留 prompt/messages 等内容，不使用业务摘要的字段隐藏规则。

模型与连接页面增加可选的“总制片代理”角色。新项目默认委托总制片。未绑定时明确显示配置问题并保留人工决策入口；不会猜测模型或假装自动选择。已有项目保留原协作方式。旧后端无该角色或相应 API 字段时安全降级，不通过前端伪造支持。

委托允许总制片在合格候选内选择故事和视觉，终片仍由出品人审阅。文本模型请求可能按供应商计费；视频付费授权和最终发布不自动进行。本页只是界面，执行权限由后端受控 gate 校验。

任务卡显示负责人、审核职责、上下游、输入/交付、实际尝试与当前版本状态。“执行已返回”不是“独立审核通过”；旧版本或缺少执行记录显示待执行。总制片请求记录不冒充实时心跳，requested 状态显示完成未确认。建议只基于文字和已有记录，不能声称看过成片。

交付材料需匹配当前项目和版本，只允许本项目 release 目录的下载链接。读取失败或过期记录仍可查看，但旧材料链接停用。平台待办始终要求人工核验，不因后端传入 platform_ready=true 就显示红果审核通过。界面不会触发生成、验收、上传或自动批准。

## 验证

Node 测试覆盖角色绑定/撤销、创建参数、旧后端兼容、历史记录、错误恢复、XSS、跨项目和路径穿越链接。Chromium 测试使用明确标注的模拟团队记录、只访问 localhost，并通过真实页面保存可选绑定和创建委托项目；验证人工终审保留、桌面/手机布局、读取失败时材料链接停用。浏览器 CPU 测试图样不是 AI 短剧质量证据。

发布前实际命令与数量记录在 PR；不把模拟后端测试称为真实模型或生产环境验收。前后端应作为同一版本完成组合回归后交付；本轮不部署到 Wkp。
