# 单集时间线剪辑（0.3.10）

关联 Issue #96。编辑器沿用原有项目、SQLite、持久 worker 与 CPU FFmpeg，不调用图像、视频或配音生成器。单集编辑保存为独立版本，原剧本、镜头素材和旧交付保留。整剧须先选择具体剧集；长剧集按其所属制作单元展开素材，不能跨集混剪。

## 操作

完成原始成片，暂停生产并等待在途任务结束后打开“时间线剪辑”。

1. 从原始成片或历史剪辑开始，填写名称。视频按24fps显示源入点、出点，可拆分、裁剪、删除和移动；进入转场支持硬切、叠化、淡入淡出。转场重叠会缩短成片，点击“确认新片长作为交付规格”明确确认。
2. 配音与字幕具有镜头关联；移动镜头时关联项一起移动，删除镜头时删除其关联项。裁剪后仍需检查时移与范围，服务器不会静默截断对白。原声、独立配音和背景音乐分别调整音量；音乐仅可从本项目既有独立音乐素材选择。不会从成片混音中推断或分离不存在的音轨。
3. 修改字幕文字和时间；改字不重新合成配音。文字变化须显式勾选已核对字幕与声音的关系。字幕时间不能重叠或越过片尾。
4. “保存为新版本”冻结源素材、帧区间、音轨、字幕和交付规格。旧版本可载入并另存，不覆盖原版本。项目冲突时草稿保留，核对最新版本后再保存。
5. “生成草稿预览”排入持久队列，通过同一 FFmpeg 路径生成真实文件。预览不是正式交付。不勾选审核授权时，“检查当前剪辑”仅运行确定性检查与生成预览；不会调用模型。
6. 明确授权后，“检查当前剪辑”使用项目冻结配置中的内网视觉审核模型，对新导出视频抽样。必要事件逐项检查，相邻镜头另检查连续性；帧样本与文件哈希、剪辑身份绑定。标签、原剧本和旧审核不能证明新剪辑已经落实剧情。样本不足为 `uncertain`，不能正式导出。
7. 只有批准事件映射、结构、片长、字幕确认、当前剪辑及媒体哈希绑定的非空抽样审核均通过，才能“正式导出”。观看新成片并明确确认后，采用此版本并进入原有出品人终审；不自动批准作品。只有显式采用才更新当前交付，旧交付及旧单集审核进入历史；新剪辑不继承旧人工通过标记。所属整剧交付包同步标记失效，新的单集末态来自该剪辑实际末帧观察。

采用后的短片从新版本的 LangGraph 终审节点继续；长剧集直接处理当前剪辑的人工终审，均不为通过终审重新拼接原素材。“重新剪辑”保留当前成片并返回时间线，不调用旧的自动拼接路线。历史项目缺少批准事件映射时可保存和预览，但须显式启用新创作合约并补齐映射才能正式导出。

取消按钮只取消该 CPU 剪辑任务，保留版本、原素材与旧交付。不会用全局暂停或取消生产任务替代剪辑取消。

## 接口及持久化

`GET /api/factory/projects/{id}/edits` 返回当前 revision、归属已验证的源目录、默认时间线、版本、任务与采用版本。`POST` 同路径使用 `action`：

- `save`：`document`、`label`，可选 `parent_id`。
- `preview` / `export`：`version_id`。
- `check`：`version_id`、可选 `authorize_review=true`。
- `adopt`：`version_id`、`confirmed=true`、`human_reviewed=true`。
- `cancel`：`job_id`。

所有写请求须有 `expected_revision` 和唯一 `request_id`；同请求重复返回原结果，不重复入队。客户端只传源 ID，不能提交任意路径或外部地址。保存后不能修改该版本正文；渲染、审核与导出回执附加在版本上。任务必须仍持有相同租约和版本身份才能发布结果。

元数据保存在现有项目快照的 `timeline_edits`，无新数据库表。媒体与审核回执保存在项目所属 `production/<slug>/edits/<version>/`，属于既有实例完整备份范围。原始交付快照保留在 `base_delivery`，采用新剪辑后仍可重新从原素材开始。新剪辑素材变化不会回写全局素材库。

剪辑审核目前只允许用户明确授权的现有内网视觉模型；没有配置、结果未知或上下文不足时保留预览并给出实际原因。未知审核提交不自动重发，不能用新版本掩盖原请求状态。云端付费审核需要独立计费授权接入，不由此入口绕过。

## 验证边界

CPU 回归使用明确标记的测试图案、测试音和模拟审核传输，检查实际帧数、转场重叠、字幕偏移、音轨、版本冲突、恢复、取消与源归属；这些不证明真实画质、声音或剧情效果。抽样审核只覆盖实际提交的帧，不能声称看过所有画面或听懂音轨，仍需用户观看终片。

隔离实例可调用 `factory.edit_validation.seed_validation_project()` 新建匿名 `is_validation` 样例。它从 `prepare_materials=true` 的暂停状态创建新记录及 CPU 媒体，不产生可被现有 worker 抢占的生成任务，不接管已有项目、不启动生产、不预填真实模型通过结论。原始项目标有“CPU时间线操作样例（非模型成片）”，配音为测试音，不能用于艺术效果验收。
