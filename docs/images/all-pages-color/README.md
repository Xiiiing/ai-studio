# 全页面配色检查

图片由`tests/browser/all-pages-color.spec.mjs`使用同一生产构建与隔离模拟API生成。桌面1440使用青柠绿、手机390使用雾紫，包含浅色和深色；另实际切换全部六款主题，检查跨模型配置、整剧总览与镜头工作台保持。图片展示界面与颜色职责，不代表模型生成效果、生产统计或真实连接验证。

覆盖：项目、素材库与未保存编辑弹窗、运行记录筛选、模型配置三个页签；整剧总览/规划/共享设定/剧集选择/流程/批次/成果；长集总览/流程，以及单元的概览/剧本与对白/素材/镜头/审核/质检/团队/费用/交付与字幕。使用非空测试数据与合成媒体，页面导航、筛选、选集及本地偏好不写业务API。

`global-*`为四个全局页面，`drama-*`为整剧总览与实际节点图，`unit-*`为镜头和交付。文件名包含显示模式和视口宽度。其余子页通过同一浏览器检查，不重复保存大量相同的表单截图。

检查渐变主题区及文字对比度、黑白正文/卡片/输入/主按钮、状态点实际语义与尺寸、普通阅读与操作区无渐变、无横向溢出、选中项可辨、零业务写请求与页面错误。布局、数据范围和跨页职责见[界面设计](../../UI_DESIGN.md#跨页面颜色覆盖)。

复现：`npm run build`后运行`npm run test:browser -- tests/browser/all-pages-color.spec.mjs`。实际cami入口的只读验证与更新备份单独记录，不将模拟页面检查视为真实模型制作验收。
