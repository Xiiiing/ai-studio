# 参考设计落地证据

默认深灰蓝`overview-{light,dark}-{1440,390}.png`及青柠绿`overview-jade-{light,dark}-{1440,390}.png`由`tests/browser/studio-design.spec.mjs`使用实际生产构建与隔离模拟API生成，展示黑白工作区与主按钮、当前工作、真实进度与打开入口共用的渐隐主题背景、大数字指标和分组卡片。当前工作区承载真实阶段、已有进度值和操作入口；`focus-jade-light-1440.png`为同一测试直接截取的当前制作区域。测试使用长中文项目名，手机按项目说明、阶段、进度、操作纵向排列，完整展示信息。

焦点项目、阶段及指标由测试API提供，不是生产统计，也不是模型质量或节省时间的证据。测试将最近项目与待处理项目分开，检查焦点确实指向需要处理的项目，并打开对应阶段；另覆盖空态创建、已有缩略图与404回退、六款主题、明暗及320/390/1440/1920宽度。浏览器检查黑白主体与主按钮不随主题染色，当前工作与操作形成连续的主题重心，统计卡保持中性，明暗模式分别融合周围面板，整体亮度差受控、文字对比度合格，标签保留红黄绿语义。原导航、总览待办分页与模型配置验证继续保留。

复现：`npm run build`后运行`npm run test:browser -- tests/browser/studio-design.spec.mjs`。设计方法及业务映射见[界面设计](../../UI_DESIGN.md#参考图与设计模型)。用户提供的原参考图未复制入仓库；品牌沿用README已有资产。
