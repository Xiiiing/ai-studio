# 参考设计落地证据

四张`overview-{light,dark}-{1440,390}.png`由`tests/browser/studio-design.spec.mjs`使用实际生产构建与隔离模拟API生成，展示浮动工作区、项目焦点卡、胶片叠卡、大数字指标和分组卡片。测试使用长中文项目名，手机隐藏装饰图形以保留完整内容。

焦点项目、阶段及指标由测试API提供，不是生产统计，也不是模型质量或节省时间的证据。测试将最近项目与待处理项目分开，检查焦点确实指向需要处理的项目，并打开对应阶段；另覆盖空态创建、六款主题、明暗及320/390/1440/1920宽度。原导航、总览待办分页与模型配置验证继续保留。

复现：`npm run build`后运行`npm run test:browser -- tests/browser/studio-design.spec.mjs`。设计方法及业务映射见[界面设计](../../UI_DESIGN.md#参考图与设计模型)。用户提供的原参考图未复制入仓库；品牌沿用README已有资产。
