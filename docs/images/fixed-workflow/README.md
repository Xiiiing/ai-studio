# 固定画布的查看与交付

合成整剧与制作单元，2026-10-18。只读浏览器操作；不调用真实模型、不创建生成任务。

- `overview-1440.png`、`overview-390.png`：桌面三列折返、手机纵向的阶段总览，后续阶段无需沿一条长横线查找。
- `notice-1440.png`、`notice-390.png`：状态徽标与说明文字按垂直中心对齐，包含手机换行。
- `employees-1440.png`、`employees-390.png`：阶段、部门、岗位使用同一张画布，岗位实际结果在固定详情区阅读。
- `delivery-1440.png`、`delivery-390.png`：点击同一画布上的交付线，阅读已核对接收内容；部门和岗位留在原位。
- `canvas-1440-dark.png`、`canvas-390-dark.png`：深色主题、独立滚动画布与固定阅读区。

复现入口：整剧的“制作”。点击阶段或部门底部展开按钮显示下一级分工，卡片主体只更新详情。桌面固定三列多行，中屏两列，手机一列；首次打开按宽度适配，后续操作不自动调整缩放。依次点击岗位、交付线、步骤分工和收起详情，确认主线与其他节点不移动，画布不改变缩放、横向或纵向滚动位置。刷新页面后恢复展开状态与画布位置。

浏览器用例：`fixed-canvas.spec.mjs` 在 1440、1024、390、320 像素及深浅主题检查坐标、镜头、展开、收起、刷新与重载；`drama-navigation.spec.mjs` 检查整剧/剧集/制作单元、真实指针点击连线、实际交付、任务归属、动效与减少动态效果；`context-manifest.spec.mjs` 检查原有输入来源追踪没有丢失。
