# 项目导航与流程查看

整剧项目的常用入口为总览、剧集、制作、成果。项目资料菜单保留全剧规划、共享设定、生成批次，原有 `plan`、`assets`、`batches` URL 与浏览器历史兼容。总览保留下一步入口；具体审核问题按需展开，完整审核与返修历史集中在规划页。

制作页默认使用完整画布，突出当前步骤和实际完成数。点击阶段或“当前步骤”打开节点详情；多步骤阶段保留内部步骤切换，只有一个步骤时省略重复导航。桌面并排查看流程与详情，手机切换为详情并支持返回全图。“材料与职责”保留输入、交付、职责及返修跳转，“执行记录”集中显示当前节点的已保存调用、原始请求响应或实际制作任务。切换视图保留挂载的文件阅读状态；定位指定调用会自动打开执行记录。

节点标题适当缩短，详情仍显示完整标题。数据流方向来自真实图边，返修线经过行间空白和外侧通道，不穿过节点；完成阶段用语义色细线连接。仅执行中的阶段播放流动与脉冲，暂停、阻塞、人工确认时不虚构数据流；减少动态效果偏好停用动画。

项目导航与查看不改变模型分配、审核、任务调度或生成；只读查看接口按需补充展示字段。[截图与复现](images/project-workflow/README.md)。

## 项目、部门与岗位的逐层查看

“项目流程”保留制作阶段的整体数据流；“部门协作”使用与实际生产工单相同的部门成员定义，可按项目 → 部门 → 岗位逐层展开。岗位可同时负责或参与多个步骤，不将一个模型配置等同于一名真人员工。

部门内部显示定义中的工作交接；点岗位可看负责/审核/协作的步骤、接收材料、实际任务与交付、模型调用和请求响应原文。步骤共有的成果和个人执行结果分开展示，历史模型与负责人以当次工单/回执为准；没有回执就明确显示暂无记录。部门排序不会把普通跨部门交接误画成返修。当前分配单独标识，不能反向补写历史。

部门总图始终保留，点击部门在当前画布下展开岗位；岗位和连线详情共用旁侧阅读区，步骤材料也在该区直接展开，不切换到另一张图。手机使用可收起的底部阅读区，可继续操作背后的图；关闭后回到原触发控件，支持 Escape 和键盘操作。关联剧集或制作单元仍可继续打开其实际工作流。普通制作单元支持 `#project=ID&tab=workflow` 直接进入。当前浏览器会话保存部门、岗位、连线和步骤位置，存储不可用时仍可在当前页面操作。

[部门与岗位截图及复现](images/department-workflow/README.md)。部门线来自只读的流程定义；部门内部与项目共用已绑定的角色和持久工单，不引入第二套调度器，也不触发生成。


## 连线、实际交付与当前工作

部门之间与岗位之间的连线均可点击或用键盘打开。总图按工作涉及顺序排布部门，合并同方向的多项交接；查看时先呈现有接收证据的内容。连线旁的简短标签与可展开交接清单是同一入口，详情给出发出岗位、接收岗位、当前状态、交付摘要及已保存结果，完整解析结果有文件时可直接阅读原文。

整剧/长集使用已有缓存和调用输入做只读内容核对：接收输入的设定、大纲或审核意见与前序结果一致、来源可唯一确定且没有时间冲突时，关联源记录与接收记录。重复内容无法唯一归属、接收之前尚未产生的结果、缺少原始输入时不建立交付关系。核对反映接收输入中存在该内容，不虚构独立网络传输事件或时间。数据结构中仅增加可选 `tasks[].received` 及结果文件入口，旧记录仍可读取。

发出方已保存的结果、调用原文和双方当前共用的文件继续可读，分别明确接收未关联或当前材料引用。分工定义不代表已交付，输出内容一致也不代表质量审核通过。展示的业务摘要有长度上限，完整内容以原文件为准。

正在工作的岗位仅来自当前状态来源，或当前步骤中属于本次运行时间范围的实际未完结任务（旧接口缺少运行信息时才按已有完成记录排除旧调用）；没有岗位回执时仅显示步骤执行中，不猜测具体员工。只有已关联到当前接收任务的连线播放处理动效；暂停、阻塞、人工等待与记录同步时停止。
