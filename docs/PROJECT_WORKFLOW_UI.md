# 项目导航与流程查看

整剧项目的常用入口为总览、剧集、制作、成果。项目资料菜单保留全剧规划、共享设定、生成批次，原有 URL 与浏览器历史兼容。

## 单一固定画布

制作页只显示一张工作流画布。阶段主线、阶段参与的部门、部门下的岗位使用同一个坐标系；桌面主线为三列多行折返，中屏两列，手机纵向展开，返修另有分支。阶段和部门卡片底部的展开按钮显示下一级内容，卡片主体只更新摘要。部门和岗位使用紧凑的卡片，收起的部门和岗位不占用预留高度；显式展开时只撑开所在行所需空间，阶段顺序和列归属保持不变。点击节点、连线、打开或关闭详情、状态刷新不会改变节点坐标或画布镜头。

桌面固定保留右侧摘要区，展示负责岗位、接收与交付概况和记录入口，不在摘要区嵌套长材料或滚动条。手机使用上方画布与下方摘要，选择节点或连线不自动滚动页面。打开、关闭完整详情卡片不会改变画布位置、尺寸或缩放。鼠标拖动空白、滚轮、触控滑动可移动画布；缩放、适应宽度与“当前步骤”是显式的画布操作。当前浏览器会话保存展开状态、缩放、画布滚动位置与选择，刷新后恢复；存储不可用时仍可操作。

点击“材料与分工”“执行记录”或“查看完整详情”打开独立详情卡片。卡片保留多步骤阶段的内部切换、材料与职责、返修要求、实际调用、请求响应原文、生产任务和输入来源追踪；卡片正文只有一个纵向阅读滚动区域，材料正文不再使用嵌套的限高滚动框。同一步骤切换材料与记录时保留已挂载的文件阅读状态。选择岗位的步骤分工也只更新卡片内容。关闭卡片返回原画布；重新加载页面先恢复摘要与画布，完整卡片由用户明确打开。用户主动打开关联剧集、制作单元或具体产品功能时，才进入其页面。

## 部门、岗位与交付

部门成员来自服务器已有定义；岗位在不同阶段可重复参与，每个阶段使用独立的岗位实例。部门收起岗位时，交接显示在部门之间；展开后细化到岗位端点。同方向、相同端点的交接合并为一条可点击连线，详情列出所有对应岗位交接。阶段连线保留全局交付方向及上下游材料。同一岗位参与多个阶段时，已接收内容绑定原始工单的来源阶段与接收阶段，当前动效不会借用其他阶段的历史交付。连线根据可见卡片绕行，交接端点随部门/岗位层级细化，支持真实鼠标点击与 Enter/Space。

岗位详情显示其本阶段的分工、已保存任务、结果、调用与当前材料。历史负责人和模型以当次回执为准；没有记录时明确说明。没有步骤归属的旧记录仍标明来源，不推断其执行阶段。此展示不新增调度器，也不改变模型、审核、生成或任务状态。

整剧/长集使用已有缓存与调用输入做只读核对：只有来源唯一、时间无冲突且实际输入包含前序结果时才关联接收证据。重复内容、缺失输入和时间冲突不建立交付关系。发出方候选结果与双方共用材料继续标明各自证据范围；不将分工定义或相同输出当作已接收或质量验收通过。

正在工作来自本次实际任务和当前步骤；只有已经关联到当前接收任务的连线播放数据流动。暂停、阻塞、人工等待、同步中过期记录停止动效；减少动态效果偏好停用动画。

## 验证

`fixed-canvas.spec.mjs` 覆盖 1440、1024、390、320 像素及深浅主题，比较节点与连线选择、卡片开关、刷新前后的坐标、画布尺寸、缩放与滚动位置；显式展开/收起只增减可见层级所需高度，保留阶段列归属；重载恢复会话镜头与展开状态，并检查连线不穿过卡片。额外覆盖长材料末尾可读且只有卡片正文产生纵向滚动。整剧和制作单元的浏览器用例保留实际记录、交付原文、输入来源追踪及关联工作流入口的验证。
