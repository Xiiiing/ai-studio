# 使用自己的模型和 API

AI Studio 在你自己的 Linux 机器上运行。你可以购买 API 完成制作，也可以使用自己的 GPU 和模型，或混合使用。Wkp 是开发者自己的部署，不是软件的依赖；安装后不会自动连接它。

## 1. 安装与首次启动

按 [部署说明](DEPLOYMENT.md) 安装 Python 控制层和工作台。新安装使用空配置，已有安装保留原配置。全 API 路线需要网络和 FFmpeg/PyAV 等 CPU 依赖，不需要 CUDA、模型权重、ComfyUI 或本地 TTS 环境。

```bash
python3.12 scripts/bootstrap.py
cp config/runtime.env.example config/runtime.env
chmod 600 config/runtime.env
```

启动后进入“模型与连接 → 服务连接”，点击“添加服务”，选择服务商。内置服务填写 API Key，默认地址和协议已配置；本地／自定义服务填写 URL 和可选 Key。使用预设模型，或点击“获取模型”勾选目录中的一个或多个模型；目录不可用时手动添加实际模型 ID。点击“保存连接”立即保存，不需要再进行页面级保存。内部编号自动维护。

“制作分工”独立设置文本创作、文本审稿、视觉审核及图像／视频／配音的模型，点击“保存分工”生效。已有逐角色分工会保留，展开“按角色单独配置”可继续调整。手机端先显示服务列表，点击服务进入详情，使用“服务列表”返回。

高级部署仍可在私有环境文件填写 `DASHSCOPE_API_KEY=...`、`MINIMAX_API_KEY=...` 等变量，并在高级连接设置登记变量名。Web、worker、CLI 和 systemd 都读取此文件；进程已有环境变量优先。文件不执行 shell，不展开 `$变量`，修改环境文件后需要重启 Web 和 worker。直接在界面保存的 Key 无需这样重启；运行中任务保留原配置快照。不要提交真实密钥。

分别启动 `python -m factory.web` 和 `python -m factory.worker`，使用实际控制层 Python 环境。浏览器打开本机工作台，进入“模型与连接”。工作台是本机管理面；远程访问沿用认证代理或 SSH 转发，不能直接监听公网。

## 2. 购买 API 的常见配置

最少可以使用两个供应商账号：百炼负责文本、视觉、图像和配音，MiniMax 负责视频。也可以分别购买其他已支持的文本 API。

| 环节 | 首批支持 | 配置方式 |
| --- | --- | --- |
| 文本、视觉理解 | OpenAI、DeepSeek、百炼、智谱、Moonshot、MiniMax、硅基流动、Claude、Gemini | 选择平台预设及模型，填写 API Key，分配角色 |
| 图像与参考图编辑 | 百炼 Qwen Image 2.1 / 3.0 | 添加图像 API 连接，选为图像生成连接 |
| 配音 | 百炼 Qwen3-TTS-Flash 非流式接口 | 添加语音 API 连接，配置默认声线、语言及角色声线映射 |
| 视频 | MiniMax 已适配图生视频接口 | 添加视频连接，选择兼容模型、时长和分辨率 |

平台地址、默认模型和密钥变量名称由预设填写，具体模型仍需账号开通。视觉审核必须选支持图片输入的模型；DeepSeek 和 MiniMax 的文本预设不会假装支持视觉。支持模型目录的接口可以在测试后用目录建议选择模型；没有目录时使用预设或手动填写实际 ID。不同平台使用各自协议，不保证未适配的模型或端点兼容。

百炼按账号地域和工作空间提供不同入口。图像／语音服务在高级设置中填写所属地域和工作空间的实际服务 URL。密钥、模型和地域必须匹配。预设通用地址不代表任何账号均可访问。

建议顺序：保存文本与视觉服务 → 保存图像／配音／视频服务 → 在制作分工中选择模型并保存 → 检查连接 → 提交小项目。默认动态漫使用生成图片加程序运镜；真人和动画路线才调用视频生成接口。图像、配音和视频的配置检查不会生成或收费，检查通过不等于实际生成成功。

角色声线高级设置示例：`{"voices":{"female":"Cherry","male":"Ethan","narrator":"Cherry"}}`。声线必须由所选云端模型支持；云端语音不自动沿用本地 Qwen 的声线名称。当前适配器发送文本、声线和语言，不承诺本地模型的全部情绪控制能力。

## 3. 自己部署的模型

文本模型可连接 Ollama、vLLM、LM Studio、llama.cpp 或兼容接口。`localhost` 指 AI Studio 后端所在机器。界面会根据 URL 填入连接范围与精确允许主机，可在高级设置调整；带鉴权的非本机接口使用 HTTPS。完整 Chat Completions 调用 URL 会转换为服务基址，自定义网关路径前缀保留。

图像／视频有两种接入方式：让 AI Studio 管理本机 ComfyUI，或连接自己已经运行的 ComfyUI。后者通过 HTTP 上传和下载，不要求共享目录，AI Studio 不会停止用户自己的服务。自定义 API 工作流及映射格式见 [模型接口说明](MODEL_PROVIDERS.md#自定义-comfyui-api-工作流)。模型文件、必要节点及参考图槽位必须兼容。

本地配音支持配置 Qwen3-TTS 的 Python 绝对路径、模型目录和角色声线，仍使用现有模型来源回执及逐句质量检查。你可以同时使用本地文本、云图像、本地配音和云视频。

## 4. 费用、恢复与验证

云图像（包括画风预览）、配音和视频在首次付费提交前要求授权明确批次。授权界面也会在早期预览的待办中出现，不要求先有镜头。未知单价需要明确确认；次数与估价额度属于应用限制，不是供应商账单硬限额。文本 API 的用量记录沿用原有机制，本版本未增加文本费用硬限额。

提交意图先写入数据库。响应丢失时不会自动再提交；请核对供应商记录。已获得响应但下载失败时，可恢复原下载。临时下载地址保存在运行目录中的权限 600 文件，不进入成片清单或配置导出；地址过期时需要人工处理，不能自动用再生成替代下载。已完成素材保存校验值，损坏时停止复用。

工作流模板和未完成云媒体的私有响应位于 `runtime/factory/workflow_templates/` 与 `runtime/factory/cloud_media_responses/`。现有可移植备份不收集这些运行文件或密钥；模板请单独导出，未完成任务迁移前需保留私有响应或先核对供应商结果。旧数据库和旧云视频记录继续可读，新媒体元数据使用新增表。

本地自动化验收使用隔离数据库、模拟 API 和真实 FFmpeg 编解码，不代表真实供应商质量或 Wkp 实测。接入自己的账号后，先检查结构化文本、图片理解、单张图片、短配音与单镜头视频，再扩大制作规模。

## 5. Key、协议与连接检查

界面直接填写的 Key 只通过保存请求中的独立 `secrets` 字段写入服务端，配置文件和查询响应只包含随机引用。私有文件为 `$DRAMA_FACTORY_DATA/model-keys.json`（默认 `runtime/factory/model-keys.json`），权限 `0600`；这是操作系统权限保护的明文存储，不是加密保险箱。Web 与 worker 必须使用同一个数据目录和运行身份。导出模型配置不包含 Key；该私有文件需要独立受限备份，不进入 Git。编辑已关联凭据的连接时，空 Key 保留原关联，新 Key 替换关联；旧引用保留供运行中任务使用。服务端 API 可通过 `secrets` 中的 `null` 清除可选凭据关联，必需鉴权的制作连接仍须提供有效来源。

“获取模型”对当前连接表单实际请求目录，使用填写的新 Key 或原凭据，不保存配置、不生成内容。目录可用仅说明接口和鉴权能够读取目录，不能证明模型能看图、按 schema 输出或生成合格素材。部分平台不提供当前前缀的目录，失败时根据官方控制台填写确切模型标识，不要据此换成另一种协议。页面上原有“检查连接”继续按配置的目录策略执行，跳过目录时明确显示尚未验证。

OpenAI 兼容协议使用 Chat Completions；Claude 使用 Anthropic Messages；Gemini 使用 generateContent；Ollama 可选原生 API。模型名称、供应商名称和 HTTP 协议不是同一件事，不能把任意视频 URL 当成文本接口。ComfyUI 工作流和 Qwen3-TTS 本机进程仍按各自方式配置。预设模型标识可以修改，以账号开通情况和实际服务目录为准。

本次重构对比 Cherry Studio、Open WebUI、LobeHub 和 AnythingLLM 的官方文档与源码，具体取舍见 [设计与验证说明](MODEL_CONNECTION_DESIGN.md)。未运行这些项目的完整生产系统。品牌图形来源见 [资源说明](PROVIDER_BRAND_ASSETS.md)。
